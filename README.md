This project is a Student Management System developed in Java, designed to simplify the process of managing student records. The application provides a user-friendly interface and integrates with a database for secure data storage and retrieval.

# Key Features:

- CRUD Operations: Create, Read, Update, and Delete student records with ease.
- Student Management: Add new student details such as name, ID, course, and contact information.
- Search Functionality: Quickly find student records using different filters.
- Update Records: Edit existing student information like course, grades, or personal details.
- Delete Records: Remove outdated or incorrect student data securely.
- Database Integration: All data is stored in a database, ensuring accuracy, consistency, and easy access.
This system provides a complete solution for educational institutions to manage student data efficiently. By automating record handling, it reduces manual workload, improves accuracy, and makes information retrieval faster. It is suitable for schools, colleges, and universities that need a reliable way to manage student details.

# Pre-requirements:

- NetBeans IDE (or any Java IDE)
- Java Development Kit (JDK 8 or higher)
- Database System (MySQL, SQLite, or PostgreSQL)
- JDBC Driver for connectivity
